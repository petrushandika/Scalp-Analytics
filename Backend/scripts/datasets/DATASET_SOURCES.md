## Cara Download Sumber yang Belum

### Roboflow (Gratis, butuh akun)
1. Daftar gratis di https://app.roboflow.com
2. Ambil API key dari https://app.roboflow.com/settings/api
3. Jalankan:
```bash
cd Backend
export ROBOFLOW_API_KEY=your_key_here
.venv/bin/python3 storage/datasets/download_all.py
```

### Kaggle (Gratis, butuh akun)
1. Daftar di https://www.kaggle.com
2. Download API token dari https://www.kaggle.com/settings → API → Create New Token
3. Simpan file ke `~/.kaggle/kaggle.json`
4. Jalankan:
```bash
cd Backend
.venv/bin/python3 storage/datasets/download_all.py
```
